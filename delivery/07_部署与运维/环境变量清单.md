# 环境变量清单

> 全量 env 配置项来自 [`backend/core/config.py`](../../backend/core/config.py) 的 `Config` 类；生产容器还额外读取 `docker-compose.prod.yml` 中的运行参数。`.env` 文件支持项目根 `.env` 或 `backend/.env`；生产 Docker 使用 `.env.prod`。

> [!warning] `ENV` 当前只支持 `local` / `test` / `prod`
> `core.config.get_config()` 只映射这三个值。当前 `docker-compose.prod.yml` 设置 `ENV=prod`。注意：`app.server` 里关闭 `/docs` 的判断写的是 `config.ENV == "production"`，所以在当前 compose 下 `/docs` / `/redoc` 不会被代码自动关闭；如需关闭，需修代码或在网关层限制访问。

> [!warning] 变更 env 后必须重启相关容器
> JWT / DB / Redis / Celery broker / OSS / TextIn / LLM 配置都在进程启动时读取。改 env 不会热生效，必须重启 API 与对应 Celery worker。

## 一、基础

| 变量名 | 必填 | 默认 | 说明 | 涉及模块 |
|---|---|---|---|---|
| `ENV` | 否 | `development`（入口默认读 `local`） | 运行环境标识。当前可用值：`local` / `test` / `prod`。 | 全局 |
| `DEBUG` | 否 | `True`（`ProductionConfig` 改为 `False`） | 调试开关。生产必须为 `false`。 | API |
| `APP_HOST` | 否 | `0.0.0.0` | `backend/main.py` 本地调试入口的 Uvicorn 监听地址。生产 gunicorn 绑定由 compose 固定为 `0.0.0.0:8000`。 | API |
| `APP_PORT` | 否 | `8000` | `backend/main.py` 本地调试入口端口。生产对外端口看 `HTTP_PORT`。 | API |
| `SENTRY_SDN` | 否 | `""` | Sentry DSN 占位。当前仓库内未实际接入。 | API |

## 二、数据库

| 变量名 | 必填 | 默认 | 说明 | 涉及模块 |
|---|---|---|---|---|
| `DATABASE_URL` | **是** | `None` | PostgreSQL 连接串（`postgresql+asyncpg://...`）。未设置时启动失败。当前生产 compose 不启动 PostgreSQL，必须指向外部/远程库。 | API / Worker / Alembic |
| `WRITER_DB_URL` | 否 | 由 `DATABASE_URL` 推导 | 写库 URL。仅在显式区分读写库时设置。 | API / Worker |
| `READER_DB_URL` | 否 | 由 `DATABASE_URL` 推导 | 读库 URL。 | API / Worker |
| `DB_POOL_SIZE` | 否 | `1` | SQLAlchemy 连接池大小。 | API / Worker |
| `DB_MAX_OVERFLOW` | 否 | `1` | 连接池溢出连接数。 | API / Worker |
| `DB_POOL_TIMEOUT` | 否 | `5` | 等待连接超时（秒）。 | API / Worker |
| `DB_POOL_RECYCLE` | 否 | `600` | 连接回收时间（秒）。 | API / Worker |

连接数粗估：

```text
(API_WORKERS + OCR_CONCURRENCY + METADATA_CONCURRENCY + EXTRACTION_CONCURRENCY)
  * (DB_POOL_SIZE + DB_MAX_OVERFLOW)
```

## 三、Redis / Celery

| 变量名 | 必填 | 默认 | 说明 | 涉及模块 |
|---|---|---|---|---|
| `REDIS_HOST` | 否 | `localhost` | 业务缓存 Redis 主机。生产 compose 内为 `redis`。 | API / Worker |
| `REDIS_PORT` | 否 | `6379` | 业务缓存 Redis 端口。 | API / Worker |
| `CELERY_BROKER_URL` | 推荐 | `redis://localhost:6379/1` | Celery broker。生产模板使用 `redis://redis:6379/11`。 | API / Worker |
| `CELERY_BACKEND_URL` | 推荐 | `redis://localhost:6379/2` | Celery result backend；也接受别名 `CELERY_RESULT_BACKEND`。生产模板使用 DB 12。 | API / Worker |
| `CELERY_RESULT_BACKEND` | 否 | 同上 | `CELERY_BACKEND_URL` 的兼容别名。 | API / Worker |
| `CELERY_TASK_ALWAYS_EAGER` | 否 | `false` | 调试用同步执行。生产严禁置 `true`。 | API / Worker |
| `CELERY_MAX_TASKS_PER_CHILD` | 否 | `20`（compose） | worker 子进程执行多少任务后回收。 | Worker |

队列与任务名定义在 [`celery_app.py`](../../backend/app/workers/celery_app.py)：

| 队列 | 任务名 |
|---|---|
| `ocr` | `eacy.ocr.process_document_ocr` |
| `metadata` | `eacy.metadata.extract_document_metadata` |
| `maintenance` | `eacy.maintenance.abandon_stale_pending_extraction_jobs` |
| `extraction` | `eacy.extraction.process_extraction_job` |

## 四、Docker 运行参数

这些变量由 `docker-compose.prod.yml` 读取，不在 `Config` 类中：

| 变量名 | 默认 | 说明 |
|---|---|---|
| `HTTP_PORT` | `80` | nginx 对外端口，映射为 `${HTTP_PORT}:80`。 |
| `API_WORKERS` | `2` | gunicorn worker 数。 |
| `API_TIMEOUT_SECONDS` | `180` | gunicorn 请求超时。 |
| `OCR_CONCURRENCY` | `1` | OCR worker 并发。 |
| `METADATA_CONCURRENCY` | `1` | Metadata/Maintenance worker 并发。 |
| `EXTRACTION_CONCURRENCY` | `2` | Extraction worker 并发。 |
| `PYTHON_IMAGE` / `NODE_IMAGE` / `NGINX_IMAGE` / `REDIS_IMAGE` | 国内镜像 | 构建/运行基础镜像覆盖。 |
| `APT_MIRROR` / `PIP_INDEX_URL` / `NPM_REGISTRY` | 国内镜像源 | 构建加速。 |

> 上线前必须替换；变更后所有已签发 token 失效，用户需要重新登录。

|---|---|---|---|---|
| `STALE_PENDING_ABANDON_ENABLED` | 否 | `true` | 是否启用 pending 抽取任务超时清理。 | celery-beat / worker-metadata |

## 修改 env 后需要重启的容器

| 变更 | 必须重启 |
|---|---|
| `JWT_*` / `ENABLE_AUTH` / SMTP / 验证码 | `api` |
| `DATABASE_URL` / `DB_*` | `api` + 所有 Celery worker + `celery-beat` |
| `CELERY_*` / `REDIS_*` | `api` + 所有 Celery worker + `celery-beat` |
| `OSS_*` | `api` + `worker-ocr` |
| `TEXTIN_*` | `worker-ocr` |
| `OPENAI_*` / `METADATA_LLM_*` | `worker-metadata`（也建议重启 `api`） |
| `EXTRACTION_*` / `EACY_EXTRACTION_STRATEGY` | `worker-extraction` |
| `STALE_PENDING_*` | `celery-beat` + `worker-metadata` |
| `HTTP_PORT` / 镜像源 | 重新 `up -d` 对应服务，镜像源变化需重新 `build` |

详细操作见 [[首次部署手册]] 与 [[升级流程]]。
